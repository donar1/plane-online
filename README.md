# 打飞机联机版 · 本地部署

按《说明文件 打飞机.html》指南落地，并在此基础上按需求做了功能改造（难度、手动布阵、布阵期移动飞机、重连体验修复）。

## 目录结构

```
plane-online/
├── package.json          项目配置（唯一依赖 ws）
├── server.js             游戏服务器（Node.js + WebSocket，权威判定）
├── start.bat             双击启动（自动装依赖 + 起服务，崩溃自动重启）
├── server.log            服务运行日志
├── public/
│   └── index.html        游戏客户端（浏览器，手机/电脑通用）
└── tests/                自测脚本（不影响游戏运行，按需手动执行）
    ├── crash_test.js     掉线回归：对端粗暴断网，验证服务端不崩
    ├── cancel_test.js    取消房间回归：房主取消 → 对手收到 room_closed → 旧房间码失效
    ├── net_count.js      广播回归：验证两个玩家都能收到每秒状态
    ├── peer_auto.js      自动对端：加入指定房间并自动准备（node tests/peer_auto.js 房间码）
    └── peer_fore.js      前台对端：加入房间、提交布局、打印对战事件
```

自测脚本依赖 `tests/` 上层的 `node_modules`，直接在 `plane-online/tests` 里 `node xxx.js` 即可，不用另装依赖。

## 启动方式

三种任选：

1. 双击 `start.bat`（最省事，会自动补装依赖）
2. 在 PowerShell / cmd 里执行 `npm start`
3. 直接 `node server.js`

看到下面这段就说明启动成功：

```
========================================
  ✈️  打飞机联机服务器已启动
========================================
  本机访问:  http://localhost:3000
```

可用环境变量覆盖默认参数，例如把部署倒计时改成 30 秒：

```powershell
$env:DEPLOY_SECONDS=30; node server.js
```

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | 3000 | 服务端口 |
| `DEPLOY_SECONDS` | 60 | 布阵倒计时秒数 |

## 部署到公网

想让朋友不连你家 WiFi 也能玩，按 [`DEPLOY-RENDER.md`](DEPLOY-RENDER.md) 部署到 Render 免费层（仓库里已备好 `render.yaml`，三步点完即可）。

## 怎么玩

1. 浏览器打开 `http://localhost:3000`
2. 在大厅选**难度**：`1 架飞机`（简单）/ `4 架飞机`（进阶）/ `5 架飞机`（困难）
   - 难度由**房主决定**，加入者自动跟随房间难度，不能自行改
3. 点「🎮 创建房间」，等待页会显示 6 位房间码
   - 不想等了就点「✖ 取消房间」：房间立即关闭回到大厅，已加入的对手会提示“房主已取消房间”并一起退回大厅
4. 另开一个**窗口或无痕窗口**访问同一地址，输入房间码加入
   - 会话存在 `sessionStorage`（每个标签页独立），同一浏览器开两个窗口互不干扰
5. 双方各自**手工摆飞机**——服务端不会替你生成
   - 点空格放置新飞机；方向键切换新飞机的朝向
   - **点已放好的飞机可以选中它**，再点任意空格即可把这个机头挪过去
   - 选中状态下方向键变成「旋转选中的那一架」
   - 「🎲 随机布阵」「↩️ 撤销」是可选辅助
6. 点「✅ 准备完成」提交布局，双方就绪后房主先手，30 秒一回合
7. 点对方棋盘开炮，打中机头即击沉整架；先击沉对方全部飞机者获胜

布阵阶段 60 秒倒计时，**超时不会自动布阵**，只提示"部署时间到"，玩家仍可继续摆放后点准备完成。

## 手机 / 另一台设备加入

- 电脑局域网 IP：**192.168.1.234**（IP 由路由器分配，重连网络后可能变化，可用 `ipconfig` 复查）
- 手机连**同一个 WiFi**，浏览器访问 `http://192.168.1.234:3000`
- 手机连不上多半是 Windows 防火墙拦了 3000 端口，放行方法：
  ```
  控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则
  → 端口 → TCP 3000 → 允许连接
  ```

## 在指南基础上修掉的问题

| 问题 | 原因 | 修法 |
| --- | --- | --- |
| 建房后看不到房间号 | 服务端建房后立刻广播状态，客户端无条件渲染棋盘，"等待对手"页一闪而过 | 服务端视图加 `oppJoined`，客户端在"未有人加入"时只显示等待页并回填房间码 |
| 一直提示"对手重连" | ① 同一浏览器两个窗口共用 localStorage，互相抢座位；② 服务端心跳 20 秒一次、一次没 pong 就 `terminate`，空闲连接被误杀后不断重连 | ① 会话改用 `sessionStorage`；② 心跳改为 60 秒无任何动静才判掉线；③ 掉线通知延迟 5 秒、5 秒内恢复不提示 |
| 重连一次，已摆好的飞机就没了 | 每次重连都走 `enterGameScreen()` 并把 `localPlanes` 清空 | `enterGameScreen(resetLayout)`，重连传 `false`，保留本地布局 |
| 服务端会突然整个退出 | 延迟掉线通知的回调里引用了一个未定义变量，任何人掉线 5 秒后抛 `ReferenceError`，进程直接死掉 | 补回变量定义；另外加了 `uncaughtException` / `unhandledRejection` 兜底，单个回调出错不再拖垮服务器；`start.bat` 改为异常退出 3 秒后自动重启 |
| 5 架随机布阵经常铺不满 | 单轮随机的成功率只有 24.4%，铺不满会静默少生成 | 改为多轮重来（最多 500 轮 × 400 次），1/3/4/5 架成功率 100%，平均 17ms |

## 常见问题

- **终端报 EADDRINUSE**：3000 端口被占用，改 `server.js` 里的 `PORT` 为 3001 后重启
- **Cannot find module 'ws'**：没装依赖，跑一次 `npm install`
- **页面空白**：`public/index.html` 缺失或路径不对，服务器只服务 `public/` 目录
- **房间丢失**：服务器重启或断线超 2 分钟会清房，重新建房即可
- **手机连不上**：先确认同一 WiFi，再按上面的防火墙步骤放行 3000 端口
